Every file here is a byte-for-byte copy of a file committed in a step repo (path `results/<file>` there). Nothing in this folder was edited. The report and dashboard read only these copies. Upstream data licences: Energy-Charts / SMARD (CC BY 4.0), World Bank Pink Sheet (CC BY 4.0), ECB, DEHSt public auction reports. Attribute when reusing.
